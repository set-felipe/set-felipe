# 👋 Welcome to my GitHub!

Hi! I'm a backend engineer passionate about infrastructure, data, and system intelligence.  
I work at the crossroads of performance, observability, and automation — turning complex behavior into insights that are clear and actionable.  
I enjoy building tools, writing logic that explains systems, and creating content that helps others understand how things really work.


---

🚀 What I Do

🧠 Work at the intersection of data, infrastructure, and intelligent automation.  
🔍 Combine analysis, observability, and system behavior to extract insights from complex environments.  
📊 Build tools that make data easier to understand, monitor, and act on — from metrics to predictions.  
⚙️ Automate processes across different stacks and containers, always aiming for clarity and reliability.  
📈 Apply statistical thinking to track trends, detect anomalies, and improve system understanding over time.  
🧪 Explore machine learning as a way to teach systems how to learn, adapt, and support decision-making.  
🗃️ Navigate different types of databases with a focus on performance, scalability, and usability.  
🎓 Share knowledge through code, tools, and content that help others go from confusion to confidence.
