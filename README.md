# 👋 Welcome to my GitHub!

Hi! I'm a NoSQL Engineer  specialized in **Redis performance**, **high availability**, and **real-time data pipelines**.  
I build tools, dashboards and training content to help developers and teams get the most out of Redis — from monitoring and benchmarking to deep-dive clustering.

---

🚀 What I Do

💡 **Redis Engineering & Optimization**  
I work with Redis internals — from replication and clustering to memory tuning, slowlog analysis, and real-time observability.

📊 **Data Visualization & Dashboards**  
I design real-time dashboards using Plotly, Dash, and Python to bring infrastructure data to life — readable, interactive, and insightful.

📈 **Statistics-Driven Thinking**  
I apply statistical tools like EMA, percentiles, outlier detection, and trend analysis to monitor, explain, and improve system behavior.

🧪 **Benchmarking & Load Analysis**  
I use redis-benchmark, memtier_benchmark, and time-based performance metrics to simulate and understand system limits.

🧠 **Machine Learning for Infra & Metrics**  
I create ML models that interpret operational data — classifying commands, spotting anomalies, and suggesting data-driven actions.

📋 **Health Scoring & Diagnostics**  
I build systems that analyze infrastructure conditions, calculate health scores, and generate readable diagnostics automatically.

🛠️ **Automation, Scripting & Containers**  
I automate Redis and data workflows using Docker, WSL2, and Python — from data collection to deployment.

🗃️ **Multi-Database Understanding**  
Beyond Redis, I explore PostgreSQL and MongoDB to build a broader sense of how systems behave, store, and scale.

🎓 **Content Creator & Educator**  
I enjoy breaking down technical topics, writing documentation, and building learning tools for anyone diving into performance, databases, and observability.
